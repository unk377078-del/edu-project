# 📚 منصة الامتحانات الإلكترونية السحابية (Online Exam Platform)

منصة امتحانات إلكترونية متكاملة Full-Stack باللغة العربية بتصميم RTL احترافي، وتعتمد كلياً على قاعدة بيانات سحابية مركزية (**Supabase PostgreSQL**) مع نظام مصادقة آمن، ومؤقت سحابي، وتصحيح تلقائي، واستخراج الأسئلة من ملفات PDF بالذكاء الاصطناعي.

---

## 🌟 مميزات المنصة

- **واجهة مستخدم عربية كاملة RTL**: تصميم متجاوب 100% مع كافة الشاشات (الهواتف، الأجهزة اللوحية، الكمبيوتر) باستخدام خط Cairo الأنيق.
- **Frontend بسيط وقوي**: مبني باستخدام **HTML + CSS + Vanilla JavaScript** بدون أي تعقيد أو أطر عمل ثقيلة، مما يجعله فائق السرعة وسهل الرفع والتعديل على أي استضافة.
- **قاعدة بيانات سحابية (Supabase PostgreSQL)**: البيانات محفوظة سحابياً وتتحمل إعادة تشغيل الخادم وتغيير الأجهزة.
- **نظام مصادقة وأمان (Auth)**:
  - تشفير كلمات المرور باستخدام `bcrypt` (10 rounds).
  - جلسات سحابية بـ `tokens` عشوائية (64-char) مشفرة ومحفوظة في جدول `sessions` مع كوكيز آمنة `HttpOnly`.
  - عزل بيانات الطلاب ومنع تسريب الإجابات النموذجية أثناء سير الامتحان.
- **لوحة تحكم الأدمن (Admin Dashboard)**:
  - 8 بطاقات إحصائيات شاملة (الطلاب، الامتحانات، المحاولات، متوسط الدرجات، أعلى وأدنى درجة، نسب النجاح والرسوب).
  - جدول تحليل أداء الأسئلة (الأقل نجاحاً والأكثر صعوبة أولاً) مع شريط تقدم ملون.
  - إدارة الامتحانات: إنشاء، تعديل، حذف، وتحديد شروط الامتحان (مدة، درجة نجاح، حد المحاولات، عشوائية الأسئلة والخيارات).
  - بنك الأسئلة: إضافة وتعديل وحذف وترتيب الأسئلة (سحب وتحريك لأعلى ولأسفل).
  - استيراد وتصدير الأسئلة بصيغة JSON مع فحص فوري للصلاحية Live Validation.
  - رفع ملفات PDF إلى Supabase Storage واستخراج الأسئلة تلقائياً بالذكاء الاصطناعي.
  - إدارة حسابات الطلاب والبحث الفوري برقم الجلوس أو الاسم أو البريد.
  - استعراض نتائج الطلاب ومراجعة إجابات كل طالب بالتفصيل.
- **بوابة الطالب (Student Dashboard)**:
  - بطاقة ترحيبية وإحصائيات الطالب الشخصية (الامتحانات المتاحة، المجتازة، متوسط درجاته).
  - عرض الامتحانات المنشورة مع زر بدء الامتحان أو استئناف المحاولات غير المكتملة.
  - تطبيق قيود المحاولات المسموحة ومنع تجاوز الحد الأقصى.
- **شاشة أداء الامتحان (Exam Taking)**:
  - مؤقت عد تنازلي متصل بالسيرفر مع تسليم تلقائي فور انتهاء الوقت.
  - حفظ فوري لكل إجابة في السحابة بمجرد النقر عليها (تنجو من تحديث الصفحة أو انقطاع النت).
  - شريط تنقل سريع بين الأسئلة (Progress Dots) بألوان توضح الأسئلة المحلولة وغير المحلولة.
  - نافذة تأكيد التسليم مع تنبيه بعدد الأسئلة المتبقية بدون إجابة.
- **شاشة عرض النتيجة (Result Page)**:
  - بطاقة النتيجة الكبرى مع حالة النجاح أو الرسوب وشريط الحالة الملون.
  - مراجعة مفصلة لكل سؤال: إجابة الطالب (أخضر للصحيحة / أحمر للخاطئة) وتوضيح الإجابة النموذجية الصحيحة (إذا سمح الامتحان بذلك).
  - إمكانية طباعة النتيجة وشهادة الامتحان بضغطة زر (`🖨️`).

## ⚙️ إعداد وتشغيل المشروع

### 1. إعداد قاعدة بيانات Supabase
1. سجل حساباً مجانياً على [Supabase.com](https://supabase.com) وأنشئ مشروعاً جديداً.
2. افتح **SQL Editor** في Supabase والصق محتويات الملف `supabase-setup/schema.sql` ثم اضغط **Run**.
3. افتح **Storage** من القائمة الجانبية وأنشئ Bucket باسم `exam-pdfs` واجعله **Private**.
4. من **Project Settings -> API** انسخ:
   - `Project URL`
   - `anon public key`
   - `service_role secret key`
5. أنشئ ملف `.env` في المجلد الرئيسي وضع القيم:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
   SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...

   # اختياري: لاستخراج الأسئلة من PDF بالذكاء الاصطناعي
   GEMINI_API_KEY=
   OPENAI_API_KEY=
   ```

### 2. تشغيل الموقع محلياً
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 🔑 الحسابات الافتراضية (Seed Data)

عند أول تشغيل مع قاعدة بيانات Supabase فارغة، يتم إنشاء الحسابات التالية تلقائياً:

| الحساب | البريد الإلكتروني | كلمة المرور | الدور |
| :--- | :--- | :--- | :--- |
| **الأدمن (المسؤول)** | `admin@exam.com` | `admin123` | مدير النظام |
| **الطالب التجريبي** | `student@exam.com` | `student123` | طالب (كود: ST001) |

*(توجد أزرار سريعة في صفحة تسجيل الدخول لملء بيانات الحسابين بضغطة زر واحدة للتجربة الفورية).*

## 🚀 كيفية الرفع والنشر (Deployment)

1. **على Vercel / Netlify / Railway**:
   - اربط المستودع، وضع المتغيرات البيئية من `.env` في إعدادات المنصة.
   - سيعمل التطبيق والـ APIs فوراً.
2. **الواجهة الثابتة (Static Hosting)**:
   - كافة ملفات `public/` هي ملفات HTML + CSS + Vanilla JS نقية تماماً، ويمكن رفعها مباشرة إلى أي استضافة ومربوطة بالخادم الخلفي أو Supabase مباشرة.
